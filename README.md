# Moonove — Creative Collective

**Entertainment · Visual Storytelling · Learning**

Moonove is a digital creative ecosystem bringing together three independent content brands under one unified identity.

## Brands

- **Moonlit Visual** — Drama recommendations, emotional edits, thrillers, and Asian drama content.
- **C.K. Drama World** — Aesthetic drama content, recommendations, and visual storytelling.
- **Learnove Academy** — NEET-focused Physics, Chemistry, Biology, PYQs, notes, and study resources.

---

## Overview

Moonove provides a single digital home for its brands, combining their individual identities with a consistent premium visual experience.

The website includes dedicated brand pages, social platform links, responsive layouts, subtle motion, atmospheric backgrounds, and a brand-based contact system.

---

## Features

- Premium dark editorial interface
- Responsive design across mobile, tablet, and desktop
- Dedicated pages for each Moonove brand
- Brand-specific visual themes
- Animated atmospheric backgrounds
- Subtle page and scroll animations
- Responsive navigation
- Social platform integration
- Brand-based contact form
- Netlify Forms with spam protection
- Custom 404 page
- SEO-ready page structure
- Privacy, Terms, Copyright, and Content Disclaimer pages
- Reduced-motion accessibility support
